# MVP Ecommerce Claw

Ecommerce MVP — Node.js + Express + React + PostgreSQL

## Stack

| Layer | Tech |
|---|---|
| Backend | Node.js 20 + Express |
| Frontend | React 18 + Vite |
| Database | PostgreSQL 16 |
| Deploy | Docker + Docker Compose |

## Quick Start

```bash
cd src && npm install && npm run dev
```
